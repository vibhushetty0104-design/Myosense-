MyoSense !!

An intelligent real-time muscle monitoring system built using ESP32 and an EMG Muscle Sensor to analyze muscle activity, estimate effort levels, and detect potential fatigue.

🚀 Features
📈 Real-time EMG signal acquisition
🧠 RMS-based muscle activation analysis
💪 Effort classification (SAFE / CAUTION / TOO HEAVY)
⚡ Automatic calibration for different users
📊 Live signal visualization through Serial Plotter
🔬 Fatigue detection using EMG signal trends
🔧 Built on ESP32 for low-cost edge computing
📡 Ready for future Bluetooth/Wi-Fi integration
🛠 Hardware Used
ESP32 DevKit V1
EMG Muscle Sensor V3.0
Surface EMG Electrodes
USB Interface
🧮 Working Principle

The system continuously acquires EMG signals from the user's muscle, calculates the Root Mean Square (RMS) value to quantify muscle activation, and classifies the effort level based on calibrated thresholds. By monitoring changes in signal amplitude over time, the system provides insights into muscle workload and fatigue.
